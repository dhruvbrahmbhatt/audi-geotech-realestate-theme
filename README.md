# Audi Geotech Real Estate Theme

A lightweight, performance-optimized, custom full-stack WordPress theme built specifically for modern real estate and geotechnical consultancy platforms. This architecture avoids clunky page-builders to deliver sub-second page loads, clean schema markup, and seamless dynamic property queries.

## 🚀 Key Technical Highlights

- **Zero Bloat Architecture:** Built from scratch using native WordPress loop structures—completely bypassing heavy frameworks like Elementor or Divi to maintain a pristine DOM tree.
- **Structured SCSS/CSS Architecture:** Managed via clean, scalable modular style directories to keep asset payloads exceptionally lean.
- **Asynchronous Javascript Asset Injection:** Minimized blocking layout scripts ensuring high Core Web Vitals performance out of the box.
- **Custom Page Template Map:** Developed dedicated templates for optimized handling of internal routing (`page-about.php`, `page-services.php`, `page-downloads.php`, `page-products.php`).
- **Granular Product Taxonomies:** Built out custom querying environments (`single-product.php` and `archive-product.php`) designed to scale cleanly across complex industrial catalog requirements.

## 🛠️ Tech Stack & Structure

- **Languages:** SCSS (41%), Vanilla JavaScript (41%), PHP Core Engine, Semantic HTML5
- **WordPress Engineering:** Custom WP_Query structures, Template Hierarchy mapping, native script/style enqueuing loops.
